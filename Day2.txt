-- Functional testing -- validation of Functionalities or Features
-- Non-Functional testing -- Focus on the Quality Attributes of Application



-- responsive
-- Performance Testing 
	-- Load Testing - Focus on whether application is working 
	as expected when provided number of Concurrent users
	accessing the application
	-- Stress Testing
       -- Focus on Breaking the application when number of 
	concurrent users are more than the prescribed limit
	-- Spike Testing
	-- Focus on Testing application behaviour when sudden increase in the number of Concurrent users
	-- Volume Testing - Focus on the behaviour of the application when it deals with large amount of data

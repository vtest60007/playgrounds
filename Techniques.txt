## 🧩 Playground Scenarios & Requirements

### 1. **Form Validation Playground (`index.html`)**
- **Boundary Value Analysis** → Age field (18–60).  
- **Equivalence Partitioning** → Email format, password rules.  
- **Error Guessing** → Empty fields, invalid characters.  
- **Decision Table Testing** → Payment + Shipping rules (COD + Express invalid).  
- **State Transition Testing** → Order states (New → Processing → Shipped → Delivered).  
- **Hidden Defect Injection** → Enterprise plan incorrectly mapped to Pro.  

---

### 2. **Shopping Cart Checkout (`shopping.html`)**
- **Boundary Value Analysis** → Quantity (1–10).  
- **Equivalence Partitioning** → Coupon codes starting with `SAVE`.  
- **Error Guessing** → Empty cart, invalid coupon, skipped selections.  
- **Decision Table Testing** → Payment + Delivery rules (COD + Same Day invalid).  
- **State Transition Testing** → Cart → Checkout → Payment → Confirmation.  
- **Hidden Defect Injection** → Double discount bug at quantity = 10.  

---

### 3. **Login & Role-Based Access (`login.html`)**
- **Boundary Value Analysis** → Username (5–12 chars), Password (6–10 chars).  
- **Equivalence Partitioning** → Password must contain digit.  
- **Error Guessing** → Empty fields, special characters.  
- **Decision Table Testing** → Role + Credentials rules (Admin requires `@admin`).  
- **State Transition Testing** → Logged Out → Login Attempt → Logged In → Logout.  
- **Hidden Defect Injection** → Admin bypass bug (`admin123` grants access).
